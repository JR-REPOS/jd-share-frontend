Download the signed Shortcut from a successful release workflow

The signed-shortcut artifact is produced only if Apple validation succeeds on the macOS runner. Sign in to GitHub to download private artifacts, unzip, then open the .shortcut file on your iPhone. A published iCloud link configured in Settings enables the main page’s Install Siri Shortcut button.

The versioned Shortcut asks for your phone-accessible frontend URL during installation and retains it in its Text action. It asks you to confirm shared links before opening review. Save your access token in that Safari origin separately. It does not need your My.JDownloader password or an API token.

Create this Shortcut once on your iPhone. It opens links in the app for review; it does not start downloads.

  1. In Shortcuts, create Send to JD Share. Enable Show in Share Sheet and accept URLs.
  2. Add Get URLs from Shortcut Input, then Combine Text using New Lines.
  3. Add URL Encode for that combined text.
  4. Add a Text action containing your phone-accessible JD Share address, followed by /#links=, then the encoded text variable. For example: https://YOUR-HOST/#links=[encoded text].
  5. Add Open URLs using the Text result.
  6. Share a link from Safari → Send to JD Share. Check the selected PC and use Find files. Nothing is selected automatically.

Open the same JD Share address in Safari first and save the app token there. No token goes into the Shortcut or shared URL. Use your phone-reachable address, not the PC’s localhost address. The link stays in the URL fragment until the page loads; the app removes the fragment after filling the form.

The steps above are the manual fallback. Unsigned drafts cannot be advertised as installable; no successful signing or real iOS acceptance is implied by this page. Action labels and Safari/home-screen storage behavior can vary by iOS version. Test on your phone.
